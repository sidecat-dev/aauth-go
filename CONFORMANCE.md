# Conformance status

This repository implements direct Agent and Person identity access,
Resource-managed opaque sessions, immediate and deferred three-party PS
authorization, bounded three-party auth-token revocation, and a bounded
four-party federated path from the editor sources pinned in
[SPECIFICATIONS.md](SPECIFICATIONS.md). It also includes Person-Server-hosted
interaction and baseline or Resource-held delivery of the auth-token
requirement. It is not a complete implementation of AAuth Core, HTTP Signature
Keys, or the companion drafts. It does not claim official or certified status.

Status terms:

- **Implemented** — an executing role path and focused negative tests cover the
  stated boundary.
- **Partial** — reusable code exists, but the stated source area is not complete
  or lacks an executing role path.
- **Not implemented** — no current supported path is claimed.
